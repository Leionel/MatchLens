## Minimal contract changes

`ClaimDraft.claims[]` contains an `assertion` from a small football vocabulary and two possible variants: `primary` and optional `conservative`. Each variant carries ID, scope, evidence refs, Fan and Analyst text. Values in prose use server-filled receipt slots. The core assertion is checked against computed facts, independent of the verifier's verdict.

Verifier returns one decision per claim: `publish` selects a valid primary; `qualify` selects a valid conservative variant of that **same true assertion**; `withhold` selects no variant. A disclaimer never repairs a false core. Unknown refs, wrong snapshot, unsupported core/scope, invalid prose or missing tool/handoff evidence close publication. No debate loop or third agent.

Flash product runs repeatedly misplaced nested variant fields. The minimal adjustment is a **flat one-claim provider wire schema**, mapped without semantic changes into canonical variants. At most one format correction per role uses the same role/session/evidence, preserves claim/assertion/scope and counts against six requests/25s. Initial and corrected outputs are retained. This adds bounded latency, not another agent.

A real Verifier found that a recovery at the window boundary was being described as part of the current recovery count. Generator revision2 moves the demo chain inside the window, retaining the failed boundary case. Revision3 records goals on the goal line and enforces the goal mouth. All chapters remain prefixes of one continuous match. A browser run invented “after the break” despite no halftime; manual review added a prompt/lexical regression. These development fixes are not held-out wins or proof that two agents eliminate semantic errors.

Runtime default: 32 requests/$1 reserved. This task's live validation explicitly extended the **same** ledger to 64 requests/$1.50 reserved for failed formats, semantic checks and browser reruns. No requests were refunded or ledger reset. Final dispatch count/known-usage estimate are in R0.1_RESULTS; production/judging funding remains separate.
