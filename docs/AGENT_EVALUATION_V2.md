## 1. 多智能体架构与角色分工

MatchLens AI 采用三方制衡的智能体协作与对抗架构：

```
       [ 真实比赛事件流 / StatsBomb Data ]
                     │
         ┌───────────┴───────────┐
         ▼                       ▼
┌──────────────────┐   ┌──────────────────┐
│  Agent A (叙事)  │   │  Agent B (战术)  │
│  - 进攻势头与高潮 │   │  - 空间倾斜与xT  │
│  - 叙事性假说生成 │   │  - 通道推进分析  │
└────────┬─────────┘   └────────┬─────────┘
         │ 提出声明 (Claims)     │
         └───────────┬───────────┘
                     ▼
       ┌───────────────────────────┐
       │     Agent C (对抗审查)    │
       │  - 质询因果断言 (Seek)     │
       │  - 检验对立证据 (Challenge)│
       └─────────────┬─────────────┘
                     ▼
       ┌───────────────────────────┐
       │   Publication Gate 2.0    │
       │  - 严谨度检验 (P-value/CI) │
       │  - 事实闭环放行 / 驳回    │
       └───────────────────────────┘
```

1. **Agent A (Narrative Broadcaster)**:
   - 职责：从时间序列事件中提炼关键叙事弧线、转折点（Turning Points）与进球动量。
   - 特点：善于发掘故事性，但容易过度推断因果联系（例如将偶然控球率提升解释为“战术压迫奏效”）。
2. **Agent B (Tactical Analyst)**:
   - 职责：提取空间九宫格占用、进攻通道利用率（Left/Center/Right）、xT 推进收益与失误密度。
   - 特点：基于客观空间几何，但易忽略比赛整体语境与时间窗口。
3. **Agent C (Sceptical Auditor / Challenger)**:
   - 职责：对 Agent A 和 B 提出的每一条 Claim 进行主动因果质询（Sceptical Challenge），寻找反例事件、检查样本量与显著性。
   - 特点：作为审计者，通过反事实推演确保所有被放行的叙事具有坚实证据。

## 2. 去公式化（Formula-free）重构对比

### 2.1 修复前伪公式审计
在第二轮深审中，我们在 `validation.py` 与 `benchmark.py` 发现了严重的科研造假模拟器代码：
```python
# 修复前的造假伪公式
acc_a = max(0.40, min(0.95, 0.78 - 0.05 * turnover_density + 0.03 * box_entries))
acc_b = max(0.50, min(0.96, 0.82 + 0.02 * field_tilt))
acc_c = max(0.60, min(0.98, 0.88 - 0.02 * turnover_density))
```
**危害**: 评测指标完全脱离真实模型表现，由生造的线性公式合成，给学术与工程评测制造虚假的“高准确率”。

### 2.2 修复后真实实测逻辑
彻底废弃所有静态预设公式。评测指标直接取自：
- 声明真实支持数 (`supported_count`)
- 真实质询驳回数 (`challenged_narrowed_count`)
- 空间九宫格事件真实命中率 (`spatial_attribution_precision`)
- Gate 2.0 真实通过率与拒绝率 (`gate_pass_rate`)

## 4. 实验结果与多智能体实测表现

### 4.1 智能体声明生成与质询收敛统计

| 比赛标识 | 产生声明总数 (Claims) | 因果类声明 (Causal) | 纯观测声明 (Observational) | Agent C 质询收拢率 (Narrowed) | Agent C 维持率 (Maintained) |
|---|---|---|---|---|---|
| `sb_wc2022_final` | 18 | 11 | 7 | 81.8% (9/11) | 100.0% (7/7) |
| `sb_cl2019_final` | 14 | 8 | 6 | 75.0% (6/8) | 100.0% (6/6) |
| `syn_default` | 8 | 5 | 3 | 80.0% (4/5) | 100.0% (3/3) |

**实测结论**:
- Agent C 对因果类声明展现出了高强度的审计能力：在真实复杂比赛中，约 75%~82% 的过度因果解释被成功收敛（Narrowed），迫使智能体缩小推论范围，仅保留具备时序先后与空间支撑的局部断言。
- 对于纯观测类声明（如“半场控球率 58%”），在无事实反例的情况下 100% 维持（Maintained），证明质询状态机没有盲目抹杀事实。

### 4.2 Gate 2.0 门禁严苛度与放行质量

| 比赛标识 | 提交故事数 (Stories) | 门禁通过数 (Approved) | 驳回数 (Rejected) | 拦截原因主导分布 |
|---|---|---|---|---|
| `sb_wc2022_final` | 6 | 4 | 2 | 存在未决质询争议 (1), 置信区间未收敛 (1) |
| `sb_cl2019_final` | 5 | 3 | 2 | 缺乏反事实支持 (2) |
| `syn_default` | 3 | 2 | 1 | 命名空间严格过滤 (1) |

**实测结论**:
- Gate 2.0 的真实放行率为 64.3%，在保证解说内容丰富度的同时，成功拦截了 35.7% 存在过度推断或争议未决的不可信稿件。

### 4.3 空间九宫格点选归因精确度

| 区域代码 (Zone ID) | 坐标物理界限 | 真实事件命中数 (`sb_wc2022_final`) | 归因事件精度 (Precision) |
|---|---|---|---|
| `Z1_1` (后场左路) | X: [0, 35], Y: [0, 22.7] | 412 | 100% (时空边界完全闭合) |
| `Z2_2` (中场中路) | X: [35, 70], Y: [22.7, 45.3] | 1,289 | 100% (时空边界完全闭合) |
| `Z3_3` (前场右路) | X: [70, 105], Y: [45.3, 68] | 328 | 100% (时空边界完全闭合) |

**实测结论**:
- 修复后的 `explain_chart` 空间点选归因机制通过几何边界精确圈定事件，100% 取消了随机取数组末尾事件冒充证据的假行为。

## 5. 消歧协议与可复现性保证

1. **唯一事实源**: 每一条被审批故事中的高潮点，均绑定至底层事件的精确 `clock_seconds` 与唯一 `event_id`。
2. **幂等质询**: 每次质询支持携带客户端 `idempotency_key`，服务端提供原子状态缓存，杜绝网络重发导致的重复降级。
3. **真实哈希溯源**: 快照元数据完全绑定 `match_id`、`scenario` 与数据流摘要 `source_digest`，彻底杜绝比赛间假借凭证。
