# MatchLens R2 Interactive Tactical Intelligence Report

## 1. Executive Summary

MatchLens R2 introduces **Interactive Tactical Intelligence & Grounded Adversarial Verification**, upgrading the platform from passive real-time monitoring to a rigorous, auditable tactical reasoning workbench. 

Following the completed R1 audit, R2 fulfills the agentic vision:
1. **Adversarial Verification**: Any tactical insight generated by the AI agent can be formally challenged by the analyst or broadcast team.
2. **Deterministic Fallbacks & State Transitions**: Challenges run through a deterministic gate (`maintained`, `narrowed`, `withdrawn`, `inconclusive`) with immutable revision tracking.
3. **Competing Hypotheses Matrix**: The AI explicitly tests alternative explanations (e.g., surface narrative vs fatigue vs opponent passive bias) rather than fixating on a single narrative.
4. **Honest Evidence Gap Disclosures**: When off-ball tracking data (optical 22-player vectors) is absent, the system explicitly disclaims unprovable spatial assertions.
5. **Constrained "Ask the Match"**: An intent-governed query engine delivering grounded answers with direct event proof chips.

## 2. Core Architectural Components

### 2.1 Typed Claim & Hypothesis Contracts (`contracts.py`)
- **`TypedClaimPlan`**: Extends insights with `claim_type`, `competing_hypotheses`, `verifier_verdict`, `evidence_gap_disclaimer`, and `revision_version`.
- **`HypothesisLabMatrix`**: Houses three competing hypotheses for every tactical moment:
  1. *Surface Narrative*: Primary visible observation (e.g. "Right flank overload driving progression").
  2. *Alternative Structural Explanation*: Underlying factor (e.g. "Opponent left midfielder failing to track back").
  3. *Causal Overreach Check*: Verification that the pattern is not merely noise or small-sample coincidence.
- **`ChallengeRequest` & `ChallengeResult`**:
  - Challenges include `overfitting_small_sample`, `opponent_passive_bias`, `causal_interpretation`, and `tactical_substitution_bias`.
  - Challenge resolution determines whether the claim should be maintained with stronger evidence, narrowed in scope, withdrawn, or flagged as inconclusive.

### 2.2 Endpoints Added to API (`main.py`)
- **`POST /api/challenge`**:
  - Accepts a claim ID, challenge type, and optional user notes.
  - Passes the claim through the adversarial resolution engine.
  - Updates the active snapshot, records a revision log entry, and returns the verdict and updated matrix.
- **`POST /api/ask`**:
  - Accepts a constrained tactical query intent (`turnover_cause`, `flank_vulnerability`, `progression_bottleneck`, `sub_impact`, `pressing_efficiency`) and target team.
  - Extracts deterministic metrics and event sequences to form a factual, grounded response with evidence chips and evidence gap reporting.
- **`Engine.view` Revisions & Hypotheses**:
  - Snapshot responses now natively include `hypotheses_matrix` and `revisions` history for zero-latency client state synchronization.

### 2.3 Frontend Workbench Components (`apps/web/app/components/`)
1. **`TacticalHypothesisLab.tsx`**:
   - Competing hypotheses cards with confidence scores, supporting signals, and Verifier verdicts (`Supported`, `Qualified`, `Rejected`, `Insufficient Evidence`).
   - "Adversarial Challenge" launcher.
2. **`AskTheMatch.tsx`**:
   - Constrained tactical prompt picker with live telemetry grounding.
   - Proof chips linking to match seconds, xT deltas, and turnover locations.
   - Evidence Gap Advisor drawer disclosing optical tracking boundaries.
3. **`ChallengeModal.tsx`**:
   - Interactive dialog allowing analysts to select challenge angles and submit notes to stress-test claims.
4. **`RevisionTimeline.tsx`**:
   - Immutable audit trail of how claims have evolved, narrowed, or been withdrawn.
5. **`AgentCollaborationFlow.tsx`**:
   - Visual 3-node agent workflow: `Tactical Analyst` -> `Adversarial Verifier` -> `Deterministic Gate`, displaying prompt tokens, latency, and gate rules.
6. **`InsightSpotlight.tsx` Workbench Tabs**:
   - Seamless tabs: `Insight Spotlight`, `Hypothesis Lab`, `Ask the Match`, `Revisions Audit`, and `Agent Pipeline`.
